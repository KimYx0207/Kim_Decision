# 决策示例

## 拆解

- 意图：选择一个方向。
- 主体：决策负责人。
- 路径：当前状态 -> 选择 -> 第一个动作 -> 信号。
- 约束：证据不足、时间有限、优先选择可逆动作。
- 验收：今天能启动一个动作。

## 结论

选择反馈最快的路径。

## 路径

- 动机：降低不确定性。
- 理解：必须先做选择，工作才不会扩散。
- 行动：运行一个测试。
- 阻力：害怕选错。
- 信号：回复、使用、付款、拒绝、失败。
- 状态变化：不确定变成证据。
- 延续动作：放大、修订、停止。

## 证据

- Confirmed: 需要做选择，选项存在。
- User-provided: 时间有限，优先可逆动作。
- Inference: 最短反馈循环能最大程度降低风险。
- Unconfirmed: 各选项的实际成本和时间。

## 数据缺口

- 未知：各选项的实际成本差异。如果选项A成本是B的3倍，风险评估会改变。请用户提供成本估算。

## 最小验证

- 目标：验证一个假设。
- 输入：一个主体群体和一个提议。
- 动作：索取一个可衡量回应。
- 输出：回应记录。
- 通过标准：回应证明产生真实移动。
- 失败信号：没有回应或回应不对。
- 下一步：保留、修订、停止。
- 不做什么：不做完整系统。

## 硬门

- Path gate: 通过 — 主体、动机和行动已定义。
- Evidence gate: 暂缓 — 成本数据未确认；仅推进最小测试。
- Minimum-test gate: 未开始 — 测试群体未定义。

## 模型校验

1. 风险
   发现：隐藏不确定性是最大风险。
   修正：只验证一个假设。

2. 反馈
   发现：没有信号就没有学习。
   修正：定义一个信号。

3. 约束
   发现：时间有限。
   修正：选择最短路径。

## 可用结果

先跑最小测试，再扩大范围。
