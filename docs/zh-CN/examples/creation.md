# 创作示例

## 拆解

- 意图：创作可用产物。
- 主体：接收者。
- 路径：看到 -> 理解 -> 相信 -> 行动。
- 约束：注意力有限。
- 验收：接收者能复述观点并行动。

## 结论

围绕一条路径创作。

## 路径

- 动机：获得有用答案。
- 理解：看到主要承诺。
- 行动：阅读或使用第一部分。
- 阻力：抽象、过长、证据弱。
- 信号：例子、结果、清单、下一步。
- 状态变化：怀疑变清楚。
- 延续动作：保存、分享、使用、购买、提问、决策。

## 证据

- Confirmed: 产物需要创作，接收者已定义。
- User-provided: 注意力有限。
- Inference: 一个清晰的主张比多个模糊主张更有效。
- Unconfirmed: 接收者是否已了解该主题。

## 数据缺口

- 未知：接收者的先验知识水平。如果是专家，从洞察开始。如果是新手，从背景开始。

## 最小验证

- 目标：验证一个信息。
- 输入：一个主张和一个例子。
- 动作：产出短版。
- 输出：草稿。
- 通过标准：接收者能复述主张。
- 失败信号：接收者觉得空。
- 下一步：只扩展通过验证的部分。
- 不做什么：第一信息没过，不加更多章节。

## 硬门

- Path gate: 通过 — 产物路径已定义（看到→理解→相信→行动）。
- Evidence gate: 暂缓 — 接收者知识水平未知；先产出短版测试。
- Minimum-test gate: 未开始 — 短版尚未产出。

## 模型校验

1. 本质
   发现：产物需要一个控制性主张。
   修正：删除次要主张。

2. 叙事
   发现：接收者需要继续看的理由。
   修正：从冲突或后果开始。

3. 证据
   发现：信任需要证明。
   修正：加入一个具体例子。

## 可用结果

先做短版，通过后再扩写。
