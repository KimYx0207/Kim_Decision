# 老金 Skill 中文参考

这个文件给人看。

运行入口是根目录的 `SKILL.md`。

## 核心规则

设定层保持抽象。

答复层允许具体。

回答用户时，可以使用真实姓名、公司、产品、案例、来源、日期、数据、命令、文件路径。前提是能增强可信度，并且不能编。

不要把具体人物写成内部角色模型。

不要写“像某某一样思考”。

把有价值的思维方式转成抽象模型。

## 核心框架

```text
意图 -> 主体 -> 路径 -> 约束 -> 证据 -> 最小验证 -> 模型 -> 硬门 -> 输出
```
