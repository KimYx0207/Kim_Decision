# Decision Example

## Breakdown

- Intent: choose one direction.
- Subject: the decision owner.
- Path: current state -> choice -> first action -> signal.
- Constraint: low evidence, limited time, reversible action preferred.
- Acceptance: one action can start today.

## Decision

Choose the direction with the shortest feedback loop.

## Path

- Motive: reduce uncertainty.
- Interpretation: a choice is needed before work expands.
- Action: run one test.
- Resistance: fear of choosing wrong.
- Signal: reply, use, payment, rejection, or failure.
- State change: uncertainty becomes evidence.
- Continuation: scale, revise, or stop.

## Evidence

- Confirmed: choice is needed, options exist.
- User-provided: time is limited, reversible action preferred.
- Inference: shortest feedback loop reduces risk most.
- Unconfirmed: actual cost and timeline of each option.

## Data gaps

- Unknown: real cost difference between options. If option A costs 3x more than B, the risk assessment changes. Ask the user to provide cost estimates.

## Minimum test

- Goal: test one assumption.
- Input: one subject group and one offer.
- Action: request one measurable response.
- Output: response record.
- Pass condition: response proves real movement.
- Fail signal: no response or wrong response.
- Next step: keep, revise, or stop.
- Do not do: build the full system.

## Gates

- Path gate: PASS — subject, motive, and action are defined.
- Evidence gate: HOLD — cost data is unconfirmed; proceed with smallest test only.
- Minimum-test gate: NOT STARTED — test subject group not yet defined.

## Model check

1. Risk
   Finding: hidden uncertainty is the largest risk.
   Fix: test one assumption.

2. Feedback
   Finding: no signal means no learning.
   Fix: define one signal.

3. Constraint
   Finding: time is limited.
   Fix: choose the shortest path.

## Usable result

Run the smallest test before expanding scope.
